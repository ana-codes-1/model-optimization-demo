Bar length = cost for the whole run, retries included. Green = correct, red = wrong. A model gets up to 3 attempts; passing on the first stops the clock. Gold ring = cheapest correct answer. Click any row to read what the model said.
Cost is a list-price estimate: measured token counts × published rates. GPT‑5.4 and o3 rates come from the Azure Retail Prices API; Claude has no Azure token meter, so its rates are Anthropic's published prices. Azure bills aggregated daily meters, never single requests, so treat these as comparisons rather than invoices.
